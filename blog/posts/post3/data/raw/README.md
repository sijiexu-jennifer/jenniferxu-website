# Raw IPUMS CPS files

The raw microdata are not redistributed because users must obtain IPUMS CPS data through their own registered accounts.

To reproduce the analysis, request the Basic Monthly CPS samples from January 2000 through December 2024 with these variables:

- `YEAR`
- `MONTH`
- `ASECFLAG`
- `WTFINL`
- `AGE`
- `SEX`
- `LABFORCE`

Download the fixed-width `.dat` file and its matching DDI `.xml` file, place both files in this folder, and use their filenames in the commands shown in the main `README.md`.
