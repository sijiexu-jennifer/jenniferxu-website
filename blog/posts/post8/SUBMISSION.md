# Blog Post 8 submission checklist

## Common criteria

- [x] States the inference question and explains why common interpretations are misleading.
- [x] Explains the methods for a reader with introductory statistics knowledge.
- [x] Interprets each result and ends with a clear takeaway.
- [x] Documents that the data are synthetic and labels every figure.
- [x] Uses separate `code`, `data`, `figures`, `interactive`, and `results` folders.
- [x] Includes complete replication instructions and programmatically generated results.

## Assignment-specific criteria

- [x] Constructs and visualizes a bootstrap distribution through repeated resampling.
- [x] Uses 2,000 repeated experiments to demonstrate approximately 95% coverage.
- [x] Simulates 25,000 test statistics under the null hypothesis.
- [x] Explains rejection regions and empirical p-values using the null-distribution figure.
- [x] Includes a working interactive demonstration for sample size, resamples, and confidence level.
