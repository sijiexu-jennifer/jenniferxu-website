# Blog Post 7: One Curve, Four Economies

This folder contains a reproducible Quarto blog post and an interactive Plotly visualization of U.S. inflation, unemployment, and the federal funds rate since 2000.

## Research question

Does one stable downward-sloping Phillips curve describe the U.S. inflation–unemployment relationship since 2000, or does the relationship shift across economic periods?

## Project structure

- `index.qmd`: blog post source
- `code/analysis.py`: data download, cleaning, summary, and visualization code
- `data/raw/`: programmatically downloaded FRED series
- `data/derived/us_macro_monthly.csv`: merged analysis data
- `figures/interactive_macro_dashboard.html`: self-contained interactive Plotly figure
- `results/`: period summaries and key results generated by the script
- `styles.css`: post-specific webpage styling
- `requirements.txt`: Python dependencies
- `SUBMISSION.md`: rubric and publishing checklist

## Reproduce the analysis

From this folder:

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 code/analysis.py
quarto render index.qmd
```

The script requires an internet connection. It downloads public CSV files directly from FRED without an API key, saves the raw files, calculates 12-month CPI inflation, merges the three monthly series, writes the results tables, and rebuilds the interactive figure.

## Data and definitions

- `CPIAUCSL`: seasonally adjusted CPI for all urban consumers; converted to a 12-month percent change.
- `UNRATE`: seasonally adjusted U.S. unemployment rate.
- `FEDFUNDS`: monthly effective federal funds rate.
- Analysis window: January 2000 through the latest month observed in all three series.

Source series are published by the U.S. Bureau of Labor Statistics and the Board of Governors of the Federal Reserve System and distributed through the Federal Reserve Bank of St. Louis FRED database.

## Interpretation limits

The analysis is descriptive. The visualization does not identify causal effects of unemployment or monetary policy on inflation. The observed relationship can shift because of supply shocks, expectations, fiscal policy, global conditions, measurement choices, and data revisions.
