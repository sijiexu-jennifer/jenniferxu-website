# Data access

This analysis uses the public-use PSID Cross-year Individual 1968-2023 file and Parent Identification 2023 file. PSID requires free registration and agreement to its Conditions of Use, so raw microdata are not redistributed with this repository.

See the project README for exact download paths and replication instructions. The analysis script reads the official fixed-width text and Stata import files directly from `~/Downloads/ind2023er/` and `~/Downloads/pid23/` by default.
